# 公開交易配對與訓練資料協定 v1

## 固定來源與目的
使用已封存 `data/research/external_traders/20261028_pilot_v2`，不重新挑帳戶、不修改來源。
重建 BTC 單一帳戶由空倉到空倉的持倉 episode，保留加減碼。成交片段、訂單及完整 episode 分別計數。
此為回溯觀察資料，不是已知最佳策略、合法歷史跟單訊號或新的 final holdout。

## 配對與成本
- 同毫秒以 start_position / end_position 銜接唯一順序，不以交易 ID 大小猜先後；無唯一順序則隔離未解部分。
- 反向成交拆成平倉與新開倉，手續費按數量比例分配；closedPnl 全歸平倉部分。
- 區間開始已有持倉、區間結束未平倉、持倉缺口或現金流對帳失敗，不進完整成果標籤。
- 完整 episode 用買賣現金流獨立核對 API closedPnl；容差為 0.00001 + 成交分段數 * 0.000001 USDC。
- fee 已含 builderFee；不再重扣。成交價已反映執行結果，無基準報價不能分拆滑價與價差，也不能再扣假設值。
- 原始 userFunding 的 nSamples 非空表示供應商提供聚合資訊。因聚合涵蓋區間未確證，只要帳戶有此類資訊，就不將該帳戶資金費硬配給個別 episode。
- 即使無聚合，也需獨立驗證區間完整性與結算邊界；本批完整淨成本標籤預設禁止。觀察到的資金費另外保存，不當零。
- 沒有原始停損、停利委託或策略意圖，不捏造預定盈虧比、R倍數或出場原因。
- 圖表畫實際成交及空倉到空倉範圍；持倉浮損益用已執行現金流 + 淨持倉 * K線收盤價 - 已支付費用，明示未含資金費、不是保證金帳戶權益。

## 訓練資料用途與隔離
- 輸出特徵、標籤、樣本 metadata、64棒序列 NPZ 與明確載入器。NPZ 禁用 pickle，使用固定欄位 allowlist。
- 特徵只用進場時間前已收盤的 15m K棒；進場時間是成交代理，不代表已知的真正訊號時間。
- 輸入不包含未來出場價、持有時間、最終損益、帳戶排行榜損益或未來成交量。
- 可用目標為 `return_before_funding`：完整成交現金流減實際手續費，再除以所有開倉名目金額；這不是帳戶 ROI，也不是含所有成本的淨報酬。
- 觀察方向作為獨立條件輸入；不得把沒有觀察到的其他方向或空手動作標成錯誤。
- 僅允許明確選擇「未含資金費研究目標」的離線研究載入；預設完整淨收益目標遇未知成本必須拒絕。
- 不自動對接既有 Transformer V3 的成本後品質閘門，不輸出 SAC reward 或專家正確動作，不更換部署模型。
- 時間範圍固定 60% / 20% / 20% 為 train / validation / research_test，label_end 跨分界者清除。
- 不用全期統計擬合 scaler。跨帳戶標籤重疊提供 inverse-concurrency 權重及重疊群，不能當獨立交易數。
- 保留正負結果，不依損益選樣本。暖機不足與序列缺口清楚記錄。

## 驗收
配對、反向、同毫秒排序、缺口、費用守恆、資金費聚合、未來擾動、切分清除、載入器安全、真實來源端到端驗證。
工程 PASS 不等於經濟優勢 PASS；30天6帳戶不足以證明跨市場或長期獲利。本次不正式訓練模型。
