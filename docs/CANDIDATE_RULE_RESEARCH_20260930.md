# BTC 15m 候選進出場規則與成本後期望值

研究日期：2026-09-30（台灣時間）。本次是規則研究與凍結預測診斷，不是新一輪模型訓練，也沒有更換模擬／實盤模型。

## 結論

**程式驗證通過，但沒有找到通過成本後期望值門檻的交易候選。**

- 7 組固定規則、4 個時間窗口、3 種成本，完成 84 組回放。
- 7 組規則的開發區間成本後平均收益全部為負，因此 `selected = null`。
- 後續 3 段期間中，7 組規則的成本後平均收益也每段皆為負。
- 最新封存的 30 個 Transformer 中，全部未通過完整品質閘門。不是每個子分數都負，但整體合格條件沒有成立。
- 只移除機率門檻、不改權重，6 組「版本 × seed」的合併向前收益仍全部為負；不能靠放寬門檻宣稱修好。

## 候選規則

基本趨勢條件：已收盤 1h EMA50 與 EMA200 同向，ADX >= 25，連續兩根小時棒確認。

| 規則 | 進場 | 出場變化 |
|---|---|---|
| R0 原規則 | 順 1h 趨勢，15m 收盤突破前 20 根最高／最低 | 2ATR 停損、4ATR 停利、最多 32 根；趨勢條件失效則下一開盤退出 |
| R1 較近停利 | 同 R0 | 停利改 2ATR，其餘同 R0 |
| R2 延長持有 | 同 R0 | 最長持有改 64 根，其餘同 R0 |
| R3 反向才退出 | 同 R0 | 趨勢變中性不退出，確認反向才退出；其他保護仍保留 |
| R4 成本預算 | 同 R0，且預估往返成本／停損距離 <= 25% | 同 R0；預估成本固定為 16bps，不使用未來實際成本篩選 |
| R5 順勢回調 | 順 1h 趨勢，前一收盤在 EMA20 反側，本根重越 EMA20 且實體同向 | 同 R0 |
| R6 區間掃高低回收 | 1h ADX < 20，刺破前 20 根高／低後收回，實體指向反轉 | 1.5ATR 停損／停利、16 根時間退出，不使用趨勢退出 |

所有前高／低都先 `shift(1)`。多空條件對稱。R1 至 R4 是單項改動；R5 改進場；R6 同時改進場與出場家族，不能把它當成純進場消融。這些是可反駁假說，沒有宣稱任一規則已獲利。

## 成本假設

| 情境 | 單邊手續費 | 單邊滑價 | 完整買賣價差 | 資金費率準備金 |
|---|---:|---:|---:|---:|
| Zero | 0 | 0 | 0 | 0 |
| Base | 5bps | 2bps | 1bps | 每跨一次 UTC 8 小時結算扣 1bps |
| Stress | 5bps | 5bps | 1bps | 同 Base |

1bps = 0.01%。Base 的基本往返成本約 0.15%，另加 funding 準備金。這是先前允許的假設，**不是你帳戶已核實的費率**。

Zero／Stress 都重新回放成交，不只是把總收益加減固定數字。滑價會改變成交價、以成交價為基準的停損停利位置及後續可交易時間，所以筆數可能不同。另提供 `gross_same_fills`，將同一組成交路徑的費用分解，避免混淆兩種比較。

### 原規則到底虧在哪裡

同一組 475 筆 Base 成交拆解：

```text
同成交路徑價格毛收益   -0.04859%
- 雙邊手續費           0.10002%
- 滑價與價差           0.05002%
- funding 準備金        0.00368%
= 成本後每筆期望值    -0.20231%
```

成本占這個負均值的約 76%，但拿掉成本也沒有證明正優勢。Zero 完整重跑均值為 -0.0536%，95% 區間跨零，因此也不能斷言真實毛優勢必定小於零；正確說法是「未取得正毛優勢證據」。

實際 Base 勝率 33.26%、平均贏家 +0.9701%、平均輸家 -0.7867%：

```text
E[淨收益] = 勝率 × 平均淨獲利 - 敗率 × 平均淨虧損
          = 0.3326 × 0.9701% - 0.6674 × 0.7867%
          ≈ -0.2023%

已實現平均賺賠比 = 0.9701 / 0.7867 ≈ 1.23
描述性損益兩平勝率 = 0.7867 / (0.9701 + 0.7867) ≈ 44.78%
```

44.78% 使用事後實現的盈虧金額計算，不能直接設為未來進場機率門檻。若有零收益交易，公式是非零盈虧條件下的描述；本例沒有零收益交易。

475 筆中，263 筆停損、112 筆停利、52 筆時間退出、48 筆趨勢退出。停利 4ATR／停損 2ATR 只是兩個價格位置，不保證每次贏 2R、輸 1R。時間退出、趨勢退出、跳空與成本都會改變實際賺賠比。

R1 將勝率提升至 40.65%，卻讓均值惡化到 -0.2567%。這是「提高勝率不等於提高期望值」的直接例子。

## 為什麼 Transformer 分數仍不能使用

### 1. 分數不是收益率

目前事件研究分數定義：

```text
return_skill = 1 - 模型 MSE / Train 固定平均值基準 MSE
probability_skill = 1 - 模型 Brier loss / Train 固定機率基準 Brier loss
prediction_skill_score = (return_skill + probability_skill) / 2
```

0 表示等同事先凍結的 Train 常數基準；負值代表預測誤差更大，不代表帳戶跌幅。分數正值也不直接表示可獲利。

最新 30 次 Test 中，29 次 return skill 為負、27 次 probability skill 為負、29 次綜合分數為負，**30 次完整研究閘門全部失敗**。

向前驗證平均綜合分數：舊特徵 A = -0.03526，新特徵 C = -0.03503，差異非常小。新特徵前兩段較差、最後一段較好，沒有一致改善。

### 2. 55% 機率門檻確實把候選全擋下來

事件模型的機率是「採取已指定方向、按照固定進出場規則，淨收益 > 2bps 的機率」，**不是 BTC 上漲機率**。

- 門檻：上述機率 >= 55%，且預測淨收益 > 0.02%。
- 30 次模型中，所有 Test 預測的最高機率只有 46.9133%。
- Train 的正標籤比率只有 31.21%～32.73%；Test 約 32.08%～36.72%。
- 所有模型各自的平均預測淨收益都小於零，範圍約 -0.3804% 至 -0.00066%。

這解釋了空手的直接機制，但不能反推「把 55% 降低就會獲利」。55% 是固定保守門檻，不是適用所有策略的數學最優值。若日後改用條件期望值門檻，必須先在訓練／校準期間建立並凍結，不能根據本次 Test 改出漂亮結果。

### 3. 拿掉機率閘門也沒有修好

保持原模型、原交易規則與「預測淨收益 > 2bps」，只停用機率條件，進行反事實診斷：

| 特徵版本 | Seed | 三段合併成交數 | 每筆淨均值 | 均值 95% 區間 |
|---|---:|---:|---:|---|
| 舊 A | 42 | 29 | -0.4766% | [-0.7192%, -0.1616%] |
| 舊 A | 137 | 120 | -0.1414% | [-0.2786%, -0.0149%] |
| 舊 A | 2026 | 63 | -0.2628% | [-0.4344%, -0.1178%] |
| 新 C | 42 | 92 | -0.0717% | [-0.1926%, +0.0525%] |
| 新 C | 137 | 108 | -0.1914% | [-0.2851%, -0.0990%] |
| 新 C | 2026 | 58 | -0.2652% | [-0.4218%, -0.1003%] |

6 組不是六份獨立市場，沒有把跨 seed 的重複交易加成更大樣本。部分單段有正均值，例如新 C seed42 最後一段 12 筆，但其區間跨零，且三段合併仍負。

只保留機率門檻則仍為 0 筆。這次沒有修改任何部署門檻。

### 4. 輸入很多，不等於有效訓練事件很多

雖然原始資料超過 17 萬根，事件篩選後，各次 Train 只有 1,060／1,336／1,639／1,919 筆，而且事件可能重疊、相依。模型約有 15.5～16 萬個參數。

這表示樣本效率是值得檢驗的問題，但不能只靠參數與筆數比例就斷定過擬合。預測標準差僅為實際收益標準差的 13.1%～28.6%，也不能單憑這點說模型壞掉，因為條件平均本來就可能比單筆結果平滑。更有力的證據是它未穩定超過常數預測，且篩出的交易仍然負期望。

### 5. 還有研究／執行契約隔離

`transformer/inference.py` 明確拒絕把 `strategy_event` 研究模型直接接入舊版 SAC／模擬盤／實盤。
事件模型學的是指定交易規則的結果，舊 SAC 接收的預測語意不同。即使數值欄位對得上，也不能直接代換。
**這是保護性限制，不是本次要移除的錯誤。**

改變進出場規則會改變標籤，舊模型權重不能自動變成新規則的分析師；需要重新標記、訓練、校準，再產生合法樣本外預測。

## 下一輪應該改哪裡

1. **先找可被否證的交易假說，再訓練大模型。** 本輪否定了「只縮停利、延長持有、放寬趨勢退出或加固定波動成本篩選就足夠」的想法。
2. **成本資料先落實。** 取得帳戶實際費率、歷史 funding、成交價差及滑價統計；不能靠將 taker 改填 maker 費率假裝省成本，限價單還需要成交率和逆向選擇模型。
3. **下一個少量假說可測更低換手的 1h／4h 決策。** 先登記同等風險和成本比較；只是研究方向，不宣稱較大週期必賺。R5／R6 近零毛收益不代表值得直接部署或混合。
4. **模型先比較簡單基準。** 在相同事件與時間切分下，加入 regularized logistic／ridge、小型樹模型，再與 Transformer 比較；保留獨立校準集，報告分數排序與分段期望值。
5. **先證明預測能改善期望值，再加入 SAC。** 淨收益目標已含成本，決策公式不能再扣一次相同成本；風控仍獨立。沒有通過前，不增加槓桿、不升 Champion。
6. **建立真正未看的向前資料。** 後續固定版本收集 shadow／paper 資料；本次已看的歷史不能再次命名為 final holdout。

沒有本輪數據支持直接混合這些負期望規則能變成正期望。只混合負均值且不改變條件分布，不會憑空產生優勢；若加狀態切換器，切換器也是需獨立驗證的新模型。

## 文獻如何使用

[AQR 的時間序列動能原始研究資料](https://www.aqr.com/insights/datasets/time-series-momentum-original-paper-data)涉及多資產、12 個月回看及月度持有；它支持研究趨勢類假說，**不證明 BTC 15m 突破規則有利可圖**。

[Bailey 等人的回測過擬合研究](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)說明大量重複嘗試造成假陽性的風險。因此本次先固定小組候選、全部揭露，沒有一直調整到出現獲利為止。本次未計算 PBO，不宣稱通過該方法。
