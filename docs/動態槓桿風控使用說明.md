# 動態槓桿風控使用說明

## 設計目的

這個功能不是讓 SAC 或 Transformer 直接任意決定槓桿，而是由獨立風控主管在
`1x～3x` 的硬限制內核准。SAC 提出正負目標部位，Transformer 提供方向機率、
預期波動與不確定度；風控主管再加入停損、停利、手續費、滑價、Spread 與帳戶
回撤，計算可用槓桿。

```text
SAC 目標部位
  -> Transformer 趨勢與機率
  -> 單帳戶／投資組合風控
  -> 動態槓桿風控
  -> 模擬成交或 Binance USD-M 下單
```

## 決策規則

1. 先算單筆風險與 Position Sizing，槓桿不會增加這個風險預算。
2. 估計完整來回成本：`2 × (手續費率 + 滑價率)`。
3. 淨風險：`停損距離 + 來回成本`。
4. 淨報酬：`max(停利距離 - 來回成本, 0)`。
5. 淨損益比：`淨報酬 ÷ 淨風險`。
6. 淨期望值：`勝率 × 淨報酬 - (1 - 勝率) × 淨風險`。
7. 依方向機率、淨損益比、不確定度、預測波動、回撤與 Spread 決定證據上限。
8. 最後選擇足以承載核准部位的最低槓桿，不會因信心高就自動放大部位。

減倉和平倉永遠可以通過，不會因 Transformer 不可用或期望值為負而被阻擋。

## 預設門檻

| 條件 | 2x | 3x |
|---|---:|---:|
| 最低方向機率 | 58% | 65% |
| 最低淨損益比 | 1.25 | 1.75 |
| 不確定度上限 | 45% | 30% |
| 帳戶回撤上限 | 5% | 2.5% |
| Spread 上限 | 8 bps | 4 bps |
| 預測波動上限 | 3% | 2% |

Transformer 沒有可辨識的機率校準紀錄時，預設最多只能使用 `1x`。正式 v3 訓練若
開啟 `probability_calibration`，推論會自動輸出
`transformer_probability_calibrated=1`；不需要人工修改 CSV。

## App 操作

### 模擬交易

1. 開啟「交易中心 → 模擬交易」。
2. 建立新帳戶時展開「動態槓桿風控」。
3. 開啟動態槓桿，將硬上限設為 `3x`；研究初期保留「機率未校準上限 1x」。
4. 執行一次模擬交易，下一根已收盤 K 線才會成交。
5. 在帳戶摘要與「機器人監控」查看核准倍率與原因。

既有帳戶可在「無人值守 → 調整動態槓桿」修改。背景機器人運行時設定會鎖定；先
安全停止，儲存設定後再啟動，避免同一輪交易讀到兩套風控。

### Testnet／Live

1. 開啟「交易中心 → 實盤交易」，先選 Testnet。
2. 頁面上方的「逐倉槓桿硬上限」決定絕對上限。
3. 在 RL 區展開「動態槓桿風控」調整門檻。
4. 先使用驗證模式；結果會顯示 `selected_leverage` 與 `leverage_reason`。
5. 實際送單時，Gateway 會在送單前要求 Binance 使用同一個 ISOLATED 槓桿。

## 紀錄位置

模擬倉：

```text
data/paper_trading/<帳戶>/account.json
data/paper_trading/<帳戶>/predictions.csv
data/paper_trading/<帳戶>/orders.csv
data/paper_trading/<帳戶>/trades.csv
data/paper_trading/<帳戶>/performance.csv
data/paper_trading/<帳戶>/positions.csv
```

Testnet／Live：

```text
data/live_trading/<環境>/cycles.csv
data/live_trading/<環境>/audit.jsonl
data/live_trading/<環境>/account_snapshots.csv
```

主要稽核欄位包含 `selected_leverage`、`required_leverage`、
`leverage_evidence_cap`、`leverage_win_probability`、`leverage_risk_reward`、
`leverage_net_expectancy` 與 `leverage_reason`。

## 重要限制

- 功能完成不代表模型已有獲利能力；2x／3x 必須通過 walk-forward、成本壓力測試、
  多 seed 與長時間 Testnet 才能考慮使用。
- 當前 smoke 模型只適合驗證流程，建議保持 `1x`。
- 調高槓桿不會提高預測準確率，只會改變保證金需求與強平距離。
- 正式模型重訓時，SAC 的訓練環境也應使用相同的交易成本、部位與槓桿限制。
