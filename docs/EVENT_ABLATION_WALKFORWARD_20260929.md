# 事件 Transformer 配對消融與向前驗證

## 研究問題

將「新增情境特徵」與「報酬頭改用 MSE」分開測試，避免同時改動後無法歸因。
底層仍是 Transformer V3。這次不訓練 SAC，不修改進場門檻，不更換部署模型。

## 預先登記

執行前保存 `artifacts/reports/20260929/event_ablation_walkforward/plan.json`，記錄來源 SHA256、完整設定、程式雜湊、套件版本與時間邊界。
凍結來源為 BTCUSDT Binance USD-M Futures 15m，176,729 根，UTC 2021-09-05 至 2026-09-20。
沒有向雲端上傳資料，沒有讀取交易憑證。

| 組別 | 特徵 | 報酬頭損失 |
|---|---|---|
| A：基準 | legacy_v1 | Smooth L1 |
| B：只改損失 | legacy_v1 | MSE |
| C：只加情境 | context_v2 | Smooth L1 |
| D：兩項皆改 | context_v2 | MSE |

所有組別使用 seeds 42、137、2026；序列 96 棒、d_model 64、2 層、4 頭、batch 64，上限 20 輪、早停耐心 5。
主體寬度與深度固定，新增特徵會增加輸入層參數，所以不能聲稱四組參數總數完全相同。
每組使用相同的新 Selection 指標 `event_prediction_skill_score`，不以舊組 validation loss 對上新組 skill，避免混入第三個因素。
這是重新訓練的配對比較，不能將 A 組直接等同先前 Kaggle 原成品。

## 第一階段：四組消融

- 只用最早 60% 原始 K 棒，約至 UTC 2024-09-14。
- 這段內部再分 Train 60%、Validation 20%、Test 20%。
- Validation 依時間再分 Calibration 與 Selection；標籤邊界 purge 33 棒，embargo 32 棒。
- Train 擬合標準化與特徵去重；Calibration 擬合機率校準；Selection 做早停選模。
- 獨立記錄 Test，但不以它挑選後續挑戰組。
- 共 4 組 × 3 seeds = 12 次訓練。

對每個配對種子與每項 skill 分別計算：

```text
特徵主效應 = ((C - A) + (D - B)) / 2
損失主效應 = ((B - A) + (D - C)) / 2
交互作用 = D - C - B + A
```

再呈現三個種子的平均、標準差、最小值與最大值。正差值代表相對改善，不代表絕對 skill 為正或策略已賺錢。
只有三個種子，不做強烈統計顯著性宣稱。特徵在特定損失下有效、另一種下失效，應保留交互作用而非只看平均。

## 第二階段：Expanding Walk-Forward

挑戰組是 B/C/D 中「第一階段三個種子 Selection skill 平均最高」者，平手按 B/C/D 順序。
即使全部負分仍選一個作研究比較，不等同取得 Champion 資格。

| Fold | 先前可用區間 | 後續 Test 區間，UTC，近似 |
|---|---|---|
| 1 | 原始資料 0-60% | 2024-09-14 至 2025-03-17 |
| 2 | 原始資料 0-70% | 2025-03-17 至 2025-09-17 |
| 3 | 原始資料 0-80% | 2025-09-17 至 2026-03-20 |

每個 fold 的先前可用區間再切 Train 75%、Calibration/Selection 合計 25%，後半依原設定各半；不把驗證標籤當成 Train 樣本。
因此較晚 fold 的驗證期也較長，這是本次固定的設計，不是最新資料滾動到最後一天的線上重訓。
Test 開頭保留 embargo，尾端剔除無法在當期完成標籤的候選；實際事件日期見每份預測 CSV。
每段重新訓練 A 與挑戰組，各 3 seeds，共 3 folds × 2 組 × 3 seeds = 18 次。總計 30 次訓練。

各 fold 之前的歷史在後續 fold 可以被納入擬合，因為當時已經發生；模型不接觸自己 Test 的標籤來訓練、校準或早停。
相鄰 fold 的 Test 不重疊，各 seed 分開串接，不把三個 seed 同一行情當成三倍交易樣本。

## 成交與成本

固定 15m 突破候選、已收盤 1h 趨勢制度、下一根開盤成交、2 ATR 停損、4 ATR 停利、最長 32 棒、冷卻 4 棒。
AI 接受條件固定為成功機率至少 55% 且預期淨收益超過 2 bps；不根據 Test 調門檻。
每側 5 bps 手續費、2 bps 滑價、完整價差 1 bp，funding 使用每 8 小時 1 bp 的雙向成本準備金。
Funding 並非歷史真實費率；稅後績效未驗證；資料是棒級而非逐筆成交撮合。
報表呈現每筆名目淨收益、勝率、期望值區間、成本敏感度，不把收益加總冒充帳戶曲線。

## 品質解讀

- MSE / Brier skill 大於零才表示勝過由 Train 擬合的固定常數。
- 研究閘門同時檢查兩項 skill、至少 30 筆過濾後交易、淨期望值區間下界大於零。
- 30 筆是最低檢查，不是實盤認證；即使通過，還需要更多市場期間、執行與帳戶層驗證。
- 全部研究成品仍 `live_eligible=false`，不可直接覆蓋現有 SAC 或交易模型。
- 最後 10% 本次不使用，但這份歷史資料曾被先前研究看過，所以 `pristine_holdout=false`。這是回溯式向前驗證，不是新的前向實盤證據。

## 操作

在專案根目錄執行，指定未存在的新輸出目錄：

```powershell
python -X utf8 scripts/run_strategy_event_study.py `
  --source outputs/kaggle_strategy_event_20260924/staging/data/btc_15m.csv `
  --config configs/transformer_strategy_event_v2.example.json `
  --output artifacts/reports/20260929/event_ablation_walkforward `
  --seeds 42 137 2026
```

本機限制 CPU 2 執行緒，使用完整研究模型而不是 smoke 縮小模型。
既有輸出目錄會被拒絕，避免覆寫。中斷時已完成模型與 `records.json` 會保留，指令目前不自動續跑或跳過成品；重新完整比較請用新輸出目錄。

| 檔案 | 用途 |
|---|---|
| plan.json | 訓練前的實驗計畫、來源與程式版本 |
| progress.json | 當前工作、輪數、已完成／總數、耗時 |
| records.json | 每個 seed / fold 的獨立結果，完成一個就保存 |
| selection.json | 挑戰組選擇與選擇當時的紀錄雜湊 |
| study.json | 平均、分散度、主效應、交互作用與向前結果 |
| runs/ | 每次模型、特徵合約、預測、訓練歷史及診斷 |
| wf_*_trades.csv | 各 seed 獨立串接的向前交易 |

## 結果

30 次完整容量訓練全部完成，本機 CPU 2 執行緒共約 **44 分 18 秒**；未使用 Kaggle。
565 項 pytest 與 4 項子測試通過。成品稽核確認 30 次設定符合計畫、配對候選及標籤完全一致、Train 基準一致、來源與程式雜湊未變、時間邊界有效。
驗證了 120 個模型／JSON 成品，另保存 60 份預測 CSV 的雜湊。

### 四組消融

下表為三種子平均，綜合 Skill 是收益 MSE skill 與機率 Brier skill 的平均，**不是報酬率**。
0 表示與只依 Train 擬合的常數基準相同，正值較好，負值較差。

| 組別 | Selection 綜合 Skill | Test 綜合 Skill | Test 種子標準差 | Test 最差種子 Skill | Test 成交數，各 seed |
|---|---:|---:|---:|---:|---|
| A 舊特徵 + Smooth L1 | 0.011175 | -0.034247 | 0.013000 | -0.048121 | 0 / 0 / 0 |
| B 舊特徵 + MSE | 0.006395 | -0.030117 | 0.006939 | -0.037237 | 0 / 0 / 0 |
| C 新特徵 + Smooth L1 | 0.008382 | -0.033689 | 0.015754 | -0.049457 | 0 / 0 / 0 |

Selection 仍是 A 最高；改動組中 C 最高，因此依計畫由 C 作向前挑戰者。

A/B 為 51 個特徵、154,955 個參數；C/D 為 71 個特徵、160,155 個參數。

### 獨立效果與交互作用

下表為 Test 的配對種子主效應；「平均 ± 標準差」是三種子分散度，不是信賴區間。

| 改動 | 報酬 Skill 效應 | 機率 Skill 效應 | 綜合 Skill 效應 | 綜合最差／最好種子效果 |
|---|---:|---:|---:|---|
| 新增情境特徵 | -0.002489 ± 0.019125 | 0.002731 ± 0.005183 | 0.000121 ± 0.007376 | -0.006493 / 0.008075 |
| Smooth L1 改為 MSE | 0.007627 ± 0.003389 | -0.000242 ± 0.000302 | 0.003693 ± 0.001762 | 0.002650 / 0.005727 |

MSE 在這一段 Test 的平均收益誤差有小幅改善，但 Selection 綜合主效應為 -0.004520，不能說跨區間穩定有效。
新特徵的平均綜合效應接近零，種子差異比平均效果大；新增更多指標並不自動提供交易優勢。
沒有穩定的正向交互作用證據，兩項一起改並未產生明確加成。

### 固定規則與交易品質

三段不經 AI 過濾的固定規則共 **475 筆**不重疊交易，所有組別及種子對應同一批交易，不能加總成六倍樣本。

- 每筆平均淨收益：**-0.20231%**，標準差約 **0.99753%**。
- 區塊 bootstrap 95% 期望值區間：**[-0.26047%, -0.13285%]**。
- 勝率：**33.263%**；最差單筆：**-3.98622%**。
- 額外增加 6 bps 成本後，每筆平均：**-0.26231%**。
- AI 過濾後，30 次訓練的各自 Test 全部零成交、研究品質閘門全部不通過。

以上是每筆入場名目金額的收益，不是本金帳戶報酬；沒有模擬 SAC 倉位、槓桿、帳戶回撤或個人稅後損益。
零成交沒有可估計的已交易期望值，因此保存為 `null`，不將它稱為獲利或成功避險的證據。

## 本次決策

1. **不升級 Champion，不替換模擬或實盤模型。** 基準 A 也沒有取得交易資格。
2. **20 個新情境特徵不列為已驗證的推薦升級。** 保留為可開關研究組，舊預設不變。
3. **MSE 保留為研究候選。** 有局部改善，但尚未勝過常數基準，也尚未做此因素的向前驗證。
4. 下一階段優先研究固定候選策略與成本後可交易性，再決定是否值得擴大模型或訓練 SAC；不要以降低 Test 門檻、增加槓桿或更多步數強迫產生交易。

完整數據：`study.json`；各次細節：`records.json`；工程稽核：`audit.json`。
程式與實驗流程通過不等同研究品質合格。本次歷史已被觀察，後續變更須使用新的預先登記方案與前向資料驗證。
