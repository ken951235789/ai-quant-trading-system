# 公開交易紀錄下載計畫 v1

## 目的與界線
收集外部交易行為研究素材，不宣稱存在可複製的獲利策略，不輸入現有 Transformer/SAC。
只使用公開唯讀來源，不登入、不讀取密鑰、不付費、不下單、不下載或執行他人的模型與程式。
原始資料保留於 Git 排除的 `data/research/external_traders/`；報告只顯示匿名代號。

## 事先固定的樣本規則
- 主來源 Hyperliquid；與 Binance USD-M BTCUSDT 不同交易場所，禁止直接拼接回測。
- 公開排行榜僅用作帳戶發現，不把排行績效當成已驗證收益。此網址未列入穩定 API 契約。
- 月成交量大於零、月 PnL 正與負各 3 個帳戶。固定字串 `external_traders_v1` 與公開地址 SHA-256 排序取前 3 名，不按獲利排名挑選。
- 樣本不代表全市場，有排行榜選擇偏誤及存活偏誤；月 PnL 也不是 BTC 專屬收益。
- 不因無 BTC、資料少、虧損或截斷而替換樣本。
- 首次執行固定最近 30 天 UTC 區間，終點為下載時 UTC 整點，保存到 plan.json；續跑不得移動區間。

## 有限下載範圍
- 每帳戶成交：時間分頁，最多 8 頁，每次上限 2000；官方僅保留最近 10000 筆。觸及上限或同毫秒分頁無進展必須警告。
- 每帳戶資金費及非資金費帳務：各最多 8 頁，依時間推進，不能把空回應當成完整歷史證據。
- 每帳戶當前永續持倉快照；快照不是固定區間末端的歷史持倉，也不代表所有帳戶模式的完整資產。
- 同場所 BTC 15m 已收盤 K 棒；最多 5000 根，不補值、不用 Binance 代理。
- 每次請求間隔至少 2 秒，最多 180 次網路嘗試（含重試），TLS 驗證、大小限制、逾時與有限重試，禁止重新導向。
- 保存官方 API 文件快照、來源目錄、取得時間、原始回應雜湊與檔案雜湊。

## 資料語意與驗收
- 成交片段 fill 不等於一筆完整進出場；B/A 代表買賣，不直接代表做多/做空。
- 分開保留 closedPnl、fee、builderFee、資金費；fee 已包含 builderFee，禁止重複扣除。
- 不把缺少費率、滑價、價差、初始持倉、其他場所對沖或入出金當成零。
- 只輸出觀察到的帳務片段，不計算未經驗證的完整帳戶報酬率或勝率。
- 重複記錄去重；同一識別鍵內容衝突時停止該資料集的正規化，不靜默保留最後一筆。
- 檢查 BTC 持倉銜接、區間兩端未平倉、K 棒缺口及未收盤排除；無法驗證完整性就保持隔離。
- 下載失敗保存已完成項目；相同目錄續跑使用已驗證快取，不覆寫舊回應。
- 工程檢查、研究可用性與實盤資格分開；本批 training_eligible=false、live_eligible=false。

## 後續最小研究
先用完整可對帳的 BTC 片段研究持有時間、加減碼與市場狀態，不能只模仿獲利交易。
若無法還原成本、起始持倉或帳務，停止績效排名與模仿學習；只作資料完整性研究。
