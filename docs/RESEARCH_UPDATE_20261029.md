## 完成的工程
- 唯讀、有限請求預算、TLS驗證、快取雜湊與來源隔離。
- 依持倉數量鏈還原同毫秒成交，歧義或缺口隔離，不依交易ID猜先後。
- 反向成交可拆成平倉及開倉，費用按數量分配並核對守恆。
- 完整持倉用成交現金流獨立核對 API closedPnl；部分成交不是完整交易。
- 圖表產生器可在本機畫出開倉、加減碼、平倉與持倉浮損益。
- 64棒×16項因果市場特徵、時間切分、跨界清除、重疊群及權重。
- 安全資料載入器預設拒絕把未知資金費當完整淨收益。

## 研究限制與負面結果
資金費存在 nSamples 彙總資料，精確涵蓋時間未確認，不能任意分攤到個別持倉。
11個完整持倉的現金流與 API PnL 有小額差異；原因未確認，沒有放寬容差或偽裝為費用。
目前標籤為 `(成交現金流 - 實際手續費) / 所有開倉名目金額`，不含資金費，不是帳戶或槓桿報酬。
價差與滑價已反映在成交價，但缺基準報價，無法獨立拆解，不重複扣假設值；稅務未驗證。
沒有原始停利停損委託，不捏造盈虧比或出場原因。
樣本沒有非交易機會的反事實標籤，也不代表交易者的完整決策過程。

**工程資料管線通過已列測試；研究充分性仍不足；正式訓練與實盤資格未通過。**
10個樣本僅適合載入與資料流程測試，不能正式訓練 Transformer/SAC 或報告泛化能力。
